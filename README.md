# 🌍 WorldPulse

WorldPulse é um observatório global vivo que coleta, organiza e exibe informações públicas do mundo em tempo quase real.

## O que ele faz
- Coleta dados 24h por dia de fontes públicas
- Organiza eventos globais (saúde, ciência, mundo)
- Armazena em banco de dados real
- Exibe tudo em um site simples e funcional

## Tecnologias
- Node.js
- Express
- SQLite
- RSS público
- HTML, CSS e JavaScript
